Display

Backlight of the round display.

Instrument: rotating card with aircraft symbol and heading bug. Whiskey compass: brass bowl with rotating card, no bug. Vertical card: card running sideways behind a window, no bug. Can also be changed on the unit.

Page shown after power-up.

Only used by the instrument style. On the unit the wheel sets the bug.

Compass

Added to the heading. Corrects how the sensor board is turned relative to the display.

Difference between magnetic and true north, east is positive (about +4.0 in northern Germany). 0 shows the magnetic heading.

Low values make the card calmer but slower, 100 switches the smoothing off.

Sensor mounting

Use if the sensor board is turned by 90 degrees.

Mirrors the X axis.

Mirrors the Y axis. Use if the heading decreases when you turn the unit clockwise.

WiFi

Name of the access point (default GS-MC- and the last four digits of the MAC address).

Leave empty to keep the current key. The default key is the MAC address.

Off by default: the WiFi radio can disturb the compass sensor. Switch it on and off on the WiFi page of the unit.

Debug and test

Prints to the USB serial port at 115200 baud.

Running
